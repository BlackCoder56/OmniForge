# OmniForge
**OmniForge is an extensible AI companion that combines conversational intelligence with real-time voice synthesis.** Built with modularity at its core, the project functions as a dynamic development sandbox designed to scale seamlessly from a voice-enabled chatbot into a multi-featured digital assistant as new capabilities are continuously integrated.

## Key Features

**Conversational AI:** Integrates with the latest Google Gemini API endpoints for intelligent, context-aware dialogue.

**Voice Synthesis:** Features low-latency audio rendering to speak responses out loud instantly.

**Extensible Architecture:** Designed intentionally for rapid feature expansion and iterative development.
